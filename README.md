# Проект банковского приложения
## Цель проекта:
 Создание нового функционала для личного кабинета клиента. Это виджет, который показывает несколько последних успешных банковских операций клиента.
## Установка:
1. Клонируйте репозиторий:
```
git clone https://github.com/Sofya-Ageeva/Banking-Application.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Функционал проекта
1. Реализованы функции шифрования номера карты и счета клиента:
- get_mask_card_number получает на вход номер карты и шифрует с 7 по 12 символ "*";
- get_mask_account получает на вход номер счета из 20 символов и выводит "**ХХХХ", где Х - последние 4 символа счета;
2. Реализована функция форматирования формата даты:
- get_date принимает на вход дату в формате "2024-03-11T02:26:18.671407" и выводит ее в читаемом виде "11.03.2024"
3. Реализованы функции сортировки дат:
- filter_by_state сортирует список со значением по умолчанию;
- sort_by_date сортирует список (по умолчанию - убывание)
4. Реализованы функции для работы с массивами транзакций:
- filter_by_currency содержит итератор для обработки транзакций по коду валюты, например "USD";
- transaction_descriptions возвращает описание каждой транзакции;
- card_number_generator генерирует номера банковских карт.
5. Реализована работа декоратора для логирования результата выполнения функции в файл или консоль.

**Параметры:**
* `filename` (опционально) — путь к файлу для записи логов. Если не указан, то вывод идёт в консоль.

6. Работа с JSON‑файлом (`src/utils.py`)
- читает JSON‑файл по указанному пути;
- возвращает список словарей с данными о финансовых транзакциях;
- при ошибках (файл не найден, пустой, не список) возвращает пустой список.
7. Конвертация валюты (`src/external_api.py`)
- принимает словарь с данными транзакции (ключи: `amount`, `currency`);
- конвертирует суммы из USD/EUR в рубли через внешний API;
- для RUB возвращает исходную сумму;
- обрабатывает ошибки API и сетевых запросов.


## Тестирование существующих функций
1. Реализованы тесты c покрытием более 80 % созданных модулей.
2. В тестах добавлены фикстуры и параметризация
3. Тесты, работающие с внешними источниками, используют `Mock` и `patch` 
для изоляции от внешних зависимостей 
4. Для запуска теста необходимо ввести в командной строке следующую команду:
```
pytest
```
5. Результаты тестирования содержаться в папке `htmlcov/`)
