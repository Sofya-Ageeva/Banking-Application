# Проект банковского приложения
## Цель проекта:
 Создание нового функционала для личного кабинета клиента. Это виджет, который показывает несколько последних успешных банковских операций клиента.
## Установка:
1. Клонируйте репозиторий:
```
git clone https://github.com/Sofya-Ageeva/Banking-Application.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Функционал проекта
1. Реализованы функции шифрования номера карты и счета клиента:
- get_mask_card_number получает на вход номер карты и шифрует с 7 по 12 символ "*";
- get_mask_account получает на вход номер счета из 20 символов и выводит "**ХХХХ", где Х - последние 4 символа счета;
2. Реализована функция форматирования формата даты:
- get_date принимает на вход дату в формате "2024-03-11T02:26:18.671407" и выводит ее в читаемом виде "11.03.2024"
3. Реализованы функции сортировки дат:
- filter_by_state сортирует список со значением по умолчанию;
- sort_by_date сортирует список (по умолчанию - убывание)

## Тестирование существующих функций
